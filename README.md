# Arindam Rathore — Portfolio

Live: **https://devarintakmashido.github.io/portfolio/**

Personal portfolio of Arindam Rathore, a backend engineer (Java · Spring Boot · Redis · PostgreSQL) based in Bengaluru.

Hand-built with plain HTML, CSS and JavaScript. No frameworks and no build step, hosted on GitHub Pages.

- **Human / JSON toggle** (press `J`): every section can be read as an API response
- **Command menu** (`⌘K` / `Ctrl K`): jump anywhere, copy email, download the résumé
- **Playground**: in-browser simulations of a sliding-window rate limiter, cache-aside redirects, and retry/backoff/failover
- Light and dark themes (`T`), responsive down to phone width, respects reduced-motion

## Run locally

```bash
python3 -m http.server 5173
```

Then open http://localhost:5173.
